# Raspberry Bridge

Addon Home Assistant che ascolta comandi su Firebase Realtime Database e invia ack.

## Configurazione
Nel campo `service_account_key` inserisci il JSON completo della service account Firebase.

## Note
- L'immagine viene scaricata da GHCR: `ghcr.io/ltartaglia/raspberry-bridge`.
- Le opzioni dell'addon vengono salvate da Home Assistant in `/data/options.json`.
