# LTartaglia Home Assistant Add-ons

Repository custom per Home Assistant.

## Add-ons inclusi
- Raspberry Bridge

## Installazione
1. In Home Assistant apri **Impostazioni > Componenti aggiuntivi > Add-on Store**.
2. Clicca menu in alto a destra (tre puntini) > **Repositories**.
3. Incolla l'URL di questa repository GitHub.
4. Apri l'addon **Raspberry Bridge** e installa.
